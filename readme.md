# Este es mi proyecto de semaforo
# se utiliza un Arduino Uno, una placa ESP32 o STM32 para controlar la lógica y los tiempos de encendido.
# Un LED rojo, un LED amarillo y un LED verde que simulan las luces del semáforo. En circuitos más avanzados, se añaden LEDs para semáforos peatonales o de múltiples vías.
# Resistencias (3 unidades): Comúnmente de 220 Ω (ohmios), conectadas en serie con cada LED para limitar la corriente eléctrica y evitar que se dañen.
# Protoboard (Placa de pruebas): Sirve como base para realizar las conexiones eléctricas entre los pines del microcontrolador y los componentes.
# Cables de conexión (Jumpers): Permiten enlazar los pines de salida digital (GPIO) de la placa con las resistencias, los LEDs y los rieles de tierra (GND).
